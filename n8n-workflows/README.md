# n8n Workflow Exports

Store the exported n8n workflow JSON files for the Haven & Co. real-estate automation project here.

## Folders
- `01-Telegram/` — Telegram bot workflows.
- `02-Website/` — Website chat, property search, and inquiry workflows.
- `03-Airtable/` — Airtable-related workflows, such as lead and property record automation.

## Uploading a workflow
1. Open the relevant folder.
2. Choose **Add file** → **Upload files**.
3. Upload the workflow exported from n8n as a `.json` file.
4. Give it a descriptive name, then commit the upload.

Do not upload credentials, API keys, access tokens, or other secrets in workflow exports.
