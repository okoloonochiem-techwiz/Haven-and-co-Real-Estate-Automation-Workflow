# 01 — Project overview

## Purpose
Haven & Co. is a real-estate discovery and automation project. It aims to make property search conversational and centralise property, lead and client information.

## Problem
Enquiries can be fragmented across messaging apps, websites and manual follow-up. Property seekers may struggle to describe requirements in a structured form, while agents need a consistent way to organise listings and enquiries.

## Intended solution
- Accept natural-language property requests.
- Extract budget, location, property type and room preferences.
- Search available property records.
- Present matches with useful details and images.
- Create or update lead information where the channel workflow supports it.
- Provide a consistent experience across messaging, web and planned voice channels.

## Users
Property seekers, property owners, agents and the project operator.

## Scope
Included: property discovery, listing retrieval, conversational request understanding, Airtable data management, Telegram interaction, website integration and a planned voice channel.

Not confirmed as complete: production-grade authentication, payments, agent assignment, fully deployed voice assistant, analytics and service-level monitoring.

## Success criteria
- Search requests are interpreted correctly.
- Results satisfy criteria or explain relaxed matching.
- Images correspond to the correct property.
- Leads are not unnecessarily duplicated.
- Errors are understandable when services fail.
- Documentation accurately represents the actual deployed build.
