# Assets

Store project assets here.

- `brand/` — approved Haven & Co. logos, icons and brand reference files.
- `property-images/` — demo property images that you have permission to publish.
- `diagrams/` — exported architecture or process diagrams.

Use descriptive filenames. Do not upload copyrighted property images without permission, personal data, or credentials. Keep screenshots with their corresponding workflow rather than in this directory.
